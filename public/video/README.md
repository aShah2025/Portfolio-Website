# ASCII wave motion source

`wave-motion.mp4` is used only as a hidden source texture for the tiny ASCII characters. Photographic video is never displayed in the intro.

Source: **8 K**, [A close up of a wave crashing on the beach](https://www.pexels.com/video/a-close-up-of-a-wave-crashing-on-the-beach-19923959/), Pexels. Original download: `https://videos.pexels.com/video-files/19923959/19923959-uhd_3840_2160_24fps.mp4`.

The [Pexels License](https://www.pexels.com/license/) permits use and modification on websites. Source and license checked November 6, 2026. Attribution is also linked from the intro.

This edit uses source seconds 0.9–13.5 at 3.5× speed, 640×360, 60 fps, H.264, no audio, with progressive MP4 loading. The source contains the unbroken lip, its plunge, and the resulting whitewater. The tiny texture avoids decoding full-resolution footage just to sample the ASCII grid.
